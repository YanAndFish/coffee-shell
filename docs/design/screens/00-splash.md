# 00 开屏 · 欢迎（新增）

源稿没有这一屏（新增）。新连接从开屏开始：画面一出现就是品牌（字标、杯子与蒸汽、标语），下面逐行写出连接正在做的事，代替以前的空白等待和“登录页闪一下再跳到选购”。开屏**从不提到 SSH 公钥**：公钥只在登录卡的“记住我”上说明（[01-login](01-login.md)）。

## 何时出现、何时离开

- **每个新连接**都先显示开屏（测试用 storage `coffee.splash` = `off` 跳过，主机不提供这个开关）。
- 开屏期间：壳层照常尝试用公钥恢复登录（`actions::start`），开屏页同时**预取商品列表**（公开接口，访客也用得上）。
- 离开（`actions::leave_splash`）的时机，取最先满足的一个：
  1. 至少显示 **900 ms**（`SPLASH_MIN`，读完品牌、看到蒸汽动一次，不会一闪而过），并且它等的事都有了结果：恢复登录有了结果；恢复成功的会员还要等商品列表有结果，这样“选购”打开时已经载入完毕，不再显示载入中；
  2. 最多 **6 s**（`SPLASH_MAX`）：后端太慢时不再等，各页显示自己的载入状态；
  3. 按 `⏎`（或 `Esc`、`space`）**跳过**。
- 去向：恢复登录成功 → “选购”，同时 Toast `欢迎回来，{用户名}` / `已通过 SSH 公钥恢复登录`；其余 → 登录页。跳过时恢复登录还没回来 → 登录页照旧显示“正在通过 SSH 公钥恢复登录…”，成功后再换成“选购”。

## 步骤行

每行 = 状态字形 + 一格空白 + 文案，字形不靠颜色区分（`✓ ✗ ○` 与转动的 `⠹`）：

| 行   | 进行中                        | 完成                       | 没有结果 / 失败                                                                                 |
| ---- | ----------------------------- | -------------------------- | ----------------------------------------------------------------------------------------------- |
| 终端 | —                             | `✓ 终端已连接 · {列}×{行}` | —                                                                                               |
| 账号 | `⠹ 正在恢复登录…`（有公钥时） | `✓ 欢迎回来，{用户名}`     | 没有公钥或没有记住的登录：`○ 请登录或以访客浏览`（`mute`）；出错：`✗ 未能恢复登录 · {错误文案}` |
| 豆单 | `⠹ 正在载入今日豆单…`         | `✓ 今日豆单 · {款数} 款`   | 空：`○ 今天还没有上架的豆子`；出错：`✗ 豆单没有载入 · {错误文案}`                               |

- 字形：`✓` 粗体 `acc2`，`✗` 粗体 `danger`，`○` `mute`，转圈 `acc`（每 100 ms 一帧，“界面动画”关闭时停在 `⠋`）。文案 `soft`，`○` 行 `mute`。错误文案照 [copy.md](../copy.md#空状态载入与错误) 的“载入失败的说明行”，从不显示错误码。
- 进度条（`thin_bar`，53 格）：已有结果的行数 ÷ 行数，`━` `acc2` / `─` `line-soft`。

## 布局

整块宽 53 格（块状字标的宽度），在系统行与状态栏之间水平、垂直居中；没有顶栏、没有页边距（与登录页相同）。自上而下：

| 部分                                | 行数             | 条件                  |
| ----------------------------------- | ---------------- | --------------------- |
| 蒸汽 + 杯子（居中）                 | 3 + 7，下空 1 行 | 高度 ≥ 32 行          |
| 块状字标                            | 5                | 总是（80 列也放得下） |
| 空行、标语（粗体 `fg`，居中）、空行 | 3                |                       |
| 步骤行                              | 3                |                       |
| 空行、进度条                        | 2                |                       |

高度 ≥ 32 行共 24 行，矮屏共 13 行；80×24 的内容区有 22 行。终端太小（<80×24）时照常换成“终端太小”页。

## 按键

| 键                    | 作用     | 底栏                                |
| --------------------- | -------- | ----------------------------------- |
| `⏎` / `Esc` / `space` | 跳过开屏 | `⏎ 跳过`（各宽度）                  |
| `?`                   | 帮助     | `? 快捷键`（M/L/XL），右端 `? 帮助` |

模式块 `欢迎 WELCOME`。没有 `1`–`4` `/` `q`（与登录页相同）。

## 动效

蒸汽与转圈随“界面动画”设置；开屏最多 6 s，不需要登录页那样的 20 秒闲置停止。
