## 行为

- **筛选**：产区精确匹配；烘焙度 `浅` = 烘焙等级 1–2、`中` = 3、`深` = 4–5；搜索对“名称 + 副标题 + 产区 + 地区 + 处理法 + 风味”做不区分大小写的子串匹配（`filtered()`）。产区数量始终按全部商品计，不随其他条件变化。
- **排序**：`推荐` = 源数据顺序；`价格 ↑/↓` 按 250g 基价；`杯测分` 从高到低。
- 任一筛选、排序或搜索变化：游标回到第 1 行，预览跟随。
- `a` 快速加入：重量 250g（缺货则取第一个有货的重量）、研磨整豆、标准袋、数量 1；Toast `已加入购物车` / `{商品名} · {重量} · {研磨} × {数量}`；导航胶囊数量 +1。
- `Esc`：清除产区、烘焙度与搜索，**不重置排序**（源稿 `setFilter({origin:0, roastF:0, search:''})`）。
- `/`：在任何应用页按下都先跳到本页，再把焦点放进搜索框；在搜索框里输入即时过滤，`⏎` 或 `Esc` 离开搜索框（保留文字），`✕` 清除。
- 鼠标：单击行选中，双击打开详情；“鼠标追踪”开启时悬停的非当前行铺 `hover` 底色（不移动游标，同源稿）。
- 游标移出可视区时列表滚动，面板右内缘显示滚动条。

### 焦点与按键

| 键                  | 作用                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| `↑` `↓` / `k` `j`   | 移动游标（到头不循环）                                                                           |
| `⏎` / `l` / `→`     | 打开详情                                                                                         |
| `a`                 | 快速加入                                                                                         |
| `f` / `r` / `s`     | 循环切换产区 / 烘焙度 / 排序                                                                     |
| `Esc`               | 清除筛选（见上）                                                                                 |
| `/`                 | 搜索                                                                                             |
| `Tab` / `Shift+Tab` | 按视觉顺序移动焦点：顶栏（导航、搜索框、账户）→ 筛选面板 → 列表 → 预览按钮；进入本页时焦点在列表 |

底栏：`‹↑↓› 移动  ‹⏎› 详情  ‹a› 加入  ‹f› 产区  ‹r› 烘焙  ‹s› 排序  ‹/› 搜索`（7 条，源稿）。

## 状态

| 状态             | 画面                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------- |
| 默认             | 如上图                                                                                    |
| 载入中（新增）   | 列表面板内居中 `⠹ 正在载入商品…`；筛选面板照常；预览面板只有标题                          |
| 载入失败（新增） | 列表面板内居中 `✗ 商品加载失败`（`danger`）+ 空行 + `[ ⏎ 重试 ]`                          |
| 无匹配           | 列表面板标题 `商品列表 · 0 款 · {排序}`，空状态居中（见下图）；预览面板只有标题；底栏不变 |
| 搜索中           | 搜索框粗框 `acc`，`‹/›` 后是输入文字，右端 `✕`；列表即时过滤                              |
| 访客             | 顶栏账户 `‹客› 访客 登录 →`；其余相同                                                     |
| 快速加入后       | Toast（成功）；胶囊数量更新；不跳页                                                       |
| 帮助 / 对话框    | 背景暗淡，模式 `帮助 HELP`                                                                |

## 实现差异

与上面的规格（含示意图）逐格对照后仍然存在的差异，以及原因：**nsh 限制**（nsh 0.6.1 终端布局 / 绘制做不到；升级到 0.7.1 后逐格复核，画面相同，只有对话框旁的字见 components.md）、**有意**（实现的做法更合适或规格自相矛盾，以实现为准）、**推迟**（能做，本阶段没做）。

| 差异                                                                                                                                                  | 原因                                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 表头下的分隔线是 `│ ──── │`，没有接到面板边框上（示意 `├────┤`）                                                                                      | nsh 限制：边框是 nsh 画的原生边框，内容盒被裁在边框内；要接成 `├┤` 只能让面板侧边知道分隔线所在的行（推迟）          |
| 列表行从面板线内 2 格开始（`│  ▶  耶加雪菲`），S 示意是 `│ ▶ 耶加雪菲`；价格列随之左移 2 格                                                           | nsh 限制：终端布局只在盒子至少有 1 列内边距时才画边框，游标行的底色带又自带 1 列（否则底色带会伸进内边距、把行挤动） |
