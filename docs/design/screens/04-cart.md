### 文案（逐字）

- 标题：`购物车 · {件数} 件`、`结算 CHECKOUT`；表头 `商品` `规格` `单价` `数量` `小计`

- 底栏：`全选`、`已选 {n} 件`、撤销条 `已删除 {商品名} · u 撤销`
- 地址块：`收货地址`、`3 更换 →`；无地址 `还没有收货地址，去地址本添加一个`（`danger`）
- 优惠码：`优惠码`、占位 `试试 TTY10`、`应用`；`✓ 已使用 TTY10 · 全单 9 折` / `✗ 优惠码无效或已过期`
- 金额：`商品小计`、`优惠`（`−¥{n}`）、`运费`（`¥12.00` 或 `包邮`）
- 免运费：`满 ¥199 包邮`（小计为 0）/ `再买 ¥{差额} 即可包邮` / `已满 ¥199 · 本单包邮`

- 加载步骤：`校验库存` → `锁定烘焙批次` → `生成订单` → `完成`
- 空状态：空杯字符画、`购物车是空的`、`1 去挑豆子`

## 行为

- 件数（标题、导航胶囊）= 所有行数量之和；`已选 {n} 件`、结算按钮 = 已勾选行的数量之和。
- 金额（服务端计算，见 [data.md](../data.md#计价)）：小计 = Σ 已勾选行的单价 × 数量；优惠 = TTY10 时 round(小计 × 10%)；运费 = 小计为 0 或 小计 − 优惠 ≥ 199 时 0，否则 12；合计 = 小计 − 优惠 + 运费。
- 免运费进度 = min(100, round((小计 − 优惠) ÷ 199 × 100))%；差额 = 199 − (小计 − 优惠)，整数。
- 勾选只影响结算；未勾选行的名称与小计改 `mute`，框为 `[ ]`。
- 删除：行立即消失，游标停在原位置（或上一行）；Toast（警告）`已从购物车移除` / `{商品名} · 按 u 撤销`；底栏出现撤销条。只保留**最近一次**删除；`u` 把它插回原位置并 Toast `已恢复` / `{商品名}`。结算成功后撤销条清除。
- 优惠码：输入框里 `⏎` 或按 `[ 应用 ]` 应用；空码清除信息；码不区分大小写、去首尾空格。结算成功后清空。
- `c` / `⏎` 结算，依次检查：
  1. 访客 → Toast（警告）`结算前请先登录` / `访客可以浏览和加购`，去登录页；登录后回到这里（D6）。
  2. 没有勾选 → Toast（警告）`还没有勾选商品` / `用 space 勾选要结算的豆子`。
  3. 没有本单地址 → Toast（警告）`请先选择收货地址` / `在地址本里按 ⏎ 指定`，去地址本。
  4. 提交：按钮换成加载块（步骤按真实阶段显示 校验库存 → 锁定烘焙批次 → 生成订单 → 完成；源稿在 30% / 60% / 90% 处切换）；成功后显示回执，已勾选的行从购物车移除，Toast `订单已提交` / `{订单号} · 下一个烘焙日出炉`。
- 本单地址：默认是默认地址；在地址本 `⏎ 用于本单` 可改。

### 焦点与按键

| 键                            | 作用                                                   |
| ----------------------------- | ------------------------------------------------------ |
| `↑` `↓` / `k` `j`             | 移动游标                                               |
| `space`                       | 勾选 / 取消当前行                                      |
| `→` `+` `=` `l` / `←` `-` `h` | 当前行数量 +1 / −1（1…min(9, 库存)）                   |
| `x` / `d` / `Delete`          | 删除当前行                                             |
| `u`                           | 撤销最近一次删除                                       |
| `a`                           | 全选 / 全不选（全部已选时取消全部）                    |
| `c` / `⏎`                     | 结算                                                   |
| `3`                           | 去地址本（“3 更换 →”）                                 |
| `Esc`                         | 回到选购                                               |
| `Tab`                         | 列表 → 全选 → 撤销条 → 更换地址 → 优惠码 → 应用 → 结算 |

光标在优惠码输入框里时，字母进入输入；`⏎` 应用，`Esc` 离开输入框。提交中只响应 `?`（源稿只屏蔽了本页键，`1`–`4` 仍能跳走，见 keymap K6）。

底栏：`‹↑↓› 移动  ‹space› 勾选  ‹←→› 数量  ‹x› 删除  ‹u› 撤销  ‹c› 结算`（6 条，源稿）。回执状态下改为 `‹⏎› 继续选购  ‹4› 查看订单  ‹1–4› 切换页面  ‹/› 搜索`（新增，源稿回执时仍显示购物车提示，见 keymap K15）。
