### 文案（逐字）

- `← Esc 返回`、`选购 / {产区} / {商品名}`
- 小节：`── 豆子档案`、`── 风味指标`
- 档案键：`产区` `庄园` `海拔` `品种` `处理法` `产季` `烘焙度` `杯测`（值 `{score} 分`）
- 风味轴：`酸度` `甜感` `醇厚` `苦度` `余韵` `香气`，值写 `{n}/10`
- `冲煮建议`、`风味`
- 面板标题 `规格 SKU`；组名 `重量` `研磨` `包装` `数量`；焦点提示 `← → 切换` / `← → 增减`
- 重量备注 `¥{该重量单价}` 或 `缺货`；包装 `标准袋`、`礼盒装 +¥20`
- 库存：`现货 {n} 份 · 每周二、五烘焙`（>10，`acc2`）/ `仅剩 {n} 份 · 售完即止`（≤10，`acc`）/ `暂时缺货`（0）
- `已选 {重量} · {研磨} · {包装}`、`SKU {编码}`、`{数量} × ¥{单价}`
- 按钮：`a 加入购物车`、`b 立即购买`

### 组件

Panel ×2、Button（default、primary、outline）、Tag（solid）、Leader、Radar、Meter、Chip（`.t-opt`）、Stepper、Panel Inset、Heading、Rule、StatusBar、Toast。

## 行为

- 打开详情（列表 ⏎ / 双击、购物车点商品名、“我的”推荐）：重量 = 250g（缺货则第一个有货的重量），研磨 = 整豆，包装 = 标准袋，数量 = 1，焦点组 = 重量。
- 单价 = round(基价 × 重量系数) + 包装加价；合计 = 单价 × 数量（两位小数）。重量备注里的价格**含当前包装加价**（源稿 `unitPrice(dp, i, W.k)`）。计价最终以服务端为准（[data.md](../data.md#计价)）。
- SKU 编码：`RT-{商品码}-{重量大写}-{研磨码}-{STD|GIFT}`，如 `RT-PNK-250G-WB-STD`、`RT-GSH-1KG-…`。
- 数量范围 1 … min(9, 库存)；越界时不动（不提示）。
- `a`：加入购物车（同 SKU 已在购物车则数量相加，上限 9，并重新勾选），Toast `已加入购物车` / `{商品名} · {重量} · {研磨} × {数量}`。
- `b`：同样加入但**不弹 Toast**，直接进入购物车（不会直接下单）。
- 服务端拒绝（库存变化等）：Toast（警告）`库存不足` / `{商品名} 仅剩 {n} 份`（新增），数量回落到可买上限。

### 焦点与按键

SKU 焦点组顺序：重量 → 研磨 → 包装 → 数量（`skuFocus` 0–3，不循环）。

| 键                  | 作用                                                                                         |
| ------------------- | -------------------------------------------------------------------------------------------- |
| `↑` `↓` / `k` `j`   | 上一 / 下一 SKU 组                                                                           |
| `←` `→` / `h` `l`   | 在焦点组里选上一 / 下一项；重量跳过缺货项；数量组为减 / 加；到头不循环                       |
| `+` `=` / `-` `_`   | 数量加 / 减（任何焦点下）                                                                    |
| `a`                 | 加入购物车                                                                                   |
| `b`                 | 立即购买                                                                                     |
| `Esc` / `Backspace` | 返回列表（保留列表的筛选与游标）                                                             |
| `Tab` / `Shift+Tab` | 按视觉顺序在返回按钮、各 Chip、Stepper、两个按钮之间移动；Tab 到某组的 Chip 时该组成为焦点组 |

鼠标：单击 Chip 选中并把焦点组移到该组；单击 Stepper 的 `−`/`+` 同时把焦点组移到数量。

底栏：`‹↑↓› 规格行  ‹←→› 选择  ‹+› 数量  ‹a› 加入  ‹b› 购买  ‹Esc› 返回`（6 条，源稿）。

## 状态

| 状态               | 画面                                                                                                           |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| 默认               | 如上图                                                                                                         |
| 缺货重量           | Chip 文字 `disabled` + 删除线，备注 `缺货`；键盘跳过，单击无效（例：粉红波旁 1kg，瑰夏 500g / 1kg）            |
| 库存紧张（≤10）    | 库存说明 `仅剩 {n} 份 · 售完即止`（`acc`）；数量上限 = 库存                                                    |
| 完全缺货（库存 0） | 库存说明 `暂时缺货`（`danger`）；`a` `b` 两个按钮 `disabled`，按键无效（源稿仍可加购，属不一致，见 keymap K9） |
| 数量焦点           | 数量组名前 `›`，行尾 `← → 增减`；其他组的 `›` 隐藏                                                             |
| 载入中（新增）     | 信息面板内居中 `⠹ 正在载入…`；SKU 面板只有标题                                                                 |
| 载入失败（新增）   | 信息面板内居中 `✗ 商品加载失败` + `[ ⏎ 重试 ]`；`Esc` 返回                                                     |
| 访客               | 与会员相同；`b` 进入购物车后结算时才要求登录                                                                   |

- 整个内容区滚动：最右列是滚动条（`┃` 滑块）；`PageUp`/`PageDown` 滚动；焦点组变化时自动滚到可见。
- 底栏：`‹←→› 选择  ‹a› 加入  ‹b› 购买  ‹Esc› 返回  ‹?› 帮助`。

### M 100×30

- 上下堆叠：信息面板（全宽）在上，SKU 面板（全宽，组名在左、Chip 在右的单行组，同 S）在下；内容区滚动，焦点组变化时自动滚到可见。
- 30 行 <32：雷达换风味条；描述最多 3 行。
- 购买行（合计 + `a` `b` 按钮）固定在内容区最后一行，不随滚动消失。

### L 130×40

- 两栏：信息面板 1fr + SKU 面板 46 列。信息面板内容约 75 列：豆子档案（31）+ 3 列 + 雷达（25）；6 行风味条（条长 10）放到雷达**下方**而不是右侧。
- SKU 面板内容 40 列：重量 Chip 仍为 8 列（4 个 + 3 间隔 = 35）。
