# 01 登录 · 注册 · 终端太小

源稿：`Main.dc.html` 的 `LOGIN` 区块、`submitLogin` / `finishLogin` / `guest` / `logout`、`HINTS.login`、`MODES.login`。差异 D4、D5、D6、D8（见 [README](../README.md#与设计稿的差异)）。

## 何时出现

- 新连接：若连接带有 SSH 公钥、且该公钥在 30 天内被“记住我”绑定过账号，**跳过本页**，直接进入“选购”，并显示 Toast `欢迎回来，{用户名}` / `已通过 SSH 公钥恢复登录`（新增）。否则显示本页。
- 访客在购物车按 `c` 结算 → Toast `结算前请先登录` / `访客可以浏览和加购`，跳到本页；登录成功后**回到购物车**（D6）。
- 会员按 `q` 退出登录 → 回到本页，Toast `已退出登录` / `按 ⏎ 重新登录`；同时删除当前公钥的“记住我”绑定。
- 访客在“我的”按 ⏎（`⏎ 去登录`）或点顶栏 `登录 →`。

### 焦点顺序与按键

焦点顺序（Tab 前进，Shift+Tab 后退，循环）：`用户名` → `密码` → `记住我` → `登录` → `访客浏览` → `注册新账号 →`。

- **初始焦点在 `用户名`**（与源稿不同：源稿初始焦点在窗口上，按 Tab 才进入输入框。真实登录时用户名为空，若不在输入框里，用户一打字 `g` 就会变成访客，见 [keymap.md](../keymap.md#源稿冲突与处理) K1）。
- 在输入框里：可打印字符进入输入；`⏎` 提交；`Tab` / `Shift+Tab` 移动；`Esc` 离开输入框（焦点回到“无焦点”）。
- 不在输入框里：`⏎` 提交、`g` 访客浏览、`?` 帮助、`Tab` 回到用户名。
- 焦点在“记住我”上：`space` / `⏎` 切换。焦点在按钮上：`⏎` / `space` 按下。
- 提交中：除 `?` 外的按键都忽略（源稿提交中仍可按 `g`，见 K2）。

## 注册（新增流程，D4）

在登录卡上按 `注册新账号 →`（Tab 到它后 ⏎，或单击）：**同一张卡原地切换**为注册模式，状态栏模式变为 `注册 SIGN UP`；`← 已有账号，去登录` 或在无焦点时按 `Esc` 切回登录。两种模式之间保留已输入的用户名，清空密码与错误。

- 字段与登录相同：`用户名`、`密码`；标签行右侧写约束（`mute`）：`2–16 个字符`、`至少 6 位`。
- 本地校验：用户名为空 → `✗ 请输入用户名`；不符合规则 → `✗ 用户名需为 2–16 个字符，可用中文、字母、数字和下划线`；密码 <6 位 → `✗ 密码至少 6 位`。
- 服务端：用户名已存在 → `✗ 这个用户名已被注册`；网络错误同登录。
- 成功：直接登录（同样合并访客购物车、按“记住我”绑定公钥），进入“选购”，Toast `注册成功，欢迎 {用户名}` / `已为你登录 · 购物车已同步`。

- 用户名规则是本规格的提议（源稿没有），后端以同一规则校验。
