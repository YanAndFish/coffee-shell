### 文案（逐字）

- `地址本`、`· {n} 条`、`设置默认收货地址，或为本单单独指定一个。当前寄往：`、`{姓名} · {地区}` 或 `未指定`
- `n 新增地址`、`新增收货地址`、`+`
- 卡片标签：`本单寄往`、`默认`、`家` / `公司` / `学校`
- 卡片按钮：`⏎ 用于本单`、`e 编辑`、`space 设为默认`、`d 删除`
- 对话框：标题 `新增地址 NEW` / `编辑地址 EDIT`；`收货人`、`手机号`（占位 `11 位手机号`）、`所在地区`（占位 `省 / 市 / 区`）、`详细地址`（占位 `街道、门牌号、楼层`）、`标签`、`家` `公司` `学校`、`设为默认`、`Esc 取消`、`⏎ 保存`
- 校验：`请填写收货人`、`请填写所在地区`、`请填写详细地址`；（新增）`手机号应为 11 位数字`

### 组件

AddressCard、Button（primary、small、danger、add）、Tag（acc2 描边、default、neutral）、Dialog、Input、Chip（`.t-pick`）、Toggle（勾选）、StatusBar、Toast。

## 行为

- 游标 `addrSel`：两列网格，`← →` 移 1、`↑ ↓` 移 2（到边界停住）。鼠标追踪开启时悬停即移动游标。
- `⏎` 用于本单：把这张设为本单地址，Toast `本单寄往这里` / `{姓名} · {地区}`，并跳到购物车。
- `space` 设为默认（已是默认时无效）：Toast `已设为默认地址` / `{地区}`。
- `d` / `x` 删除（无确认，同源稿）：Toast（警告）`已删除地址` / `{姓名} · {地区}`。删的是默认地址 → 剩下的第一张成为默认；删的是本单地址 → 本单地址改为新的默认地址，没有则“未指定”。
- `n` 新增、`e` 编辑：打开对话框（下节）。
- `Esc`：回到购物车。
- 电话在卡片上打码 `138 **** 5521`（11 位数字时：前 3 + `****` + 后 4）；空电话显示 `—`。

- 70×23 双线框，居中于第 1 行与状态栏之间（XL 左上角 (45, 13)）；背景暗淡；模式 `编辑 INSERT`。
- 内容区 62 列：`收货人`（30）与 `手机号`（30）两列，间隔 2；`所在地区`、`详细地址` 整行；输入框 3 行，标签在上方。
- 标签行：`标签` + 3 个 `.t-pick` Chip（选中 `▐ 家 ▌`）；同一行右对齐 `[ ] 设为默认`。
- 底部右对齐：`[ Esc 取消 ]` + 2 列 + `▐ ⏎ 保存 ▌`。
- 新增时：所有字段为空，标签默认 `家`；“设为默认”在没有任何地址时预先勾选。编辑时：带入原值；**电话显示完整号码**（源稿带入的是打码后的字符串，再保存就把号码丢了，见 keymap K10）。
- 保存：按 收货人 → 所在地区 → 详细地址 的顺序校验，第一个为空的字段报错（插入错误行，对话框高 25）；手机号非空且不是 11 位数字时报 `手机号应为 11 位数字`（新增）。成功后关闭，游标移到这张卡，Toast `已新增地址` / `地址已更新` + `{地区} {详细地址}`。勾选了“设为默认”的会成为唯一默认；第一条地址自动成为默认与本单地址。
- 任何字段改动后错误消失。

焦点顺序：`收货人` → `手机号` → `所在地区` → `详细地址` → 标签（组内 `← →` 选择）→ `设为默认`（`space` 切换）→ `Esc 取消` → `⏎ 保存`。打开时焦点在 `收货人`；`⏎` 在任何位置都是保存；`Esc` 取消并把焦点还给打开它的卡片 / 按钮。

底栏（对话框）：`‹Tab› 下一项  ‹←→› 标签  ‹space› 设为默认  ‹⏎› 保存  ‹Esc› 取消`（新增；源稿对话框打开时仍显示地址本提示）。

## 实现差异

与上面的规格（含示意图）逐格对照后仍然存在的差异，以及原因：**nsh 限制**（nsh 0.6.1 终端布局 / 绘制做不到；升级到 0.7.1 后逐格复核，画面相同，只有对话框旁的字见 components.md）、**有意**（实现的做法更合适或规格自相矛盾，以实现为准）、**推迟**（能做，本阶段没做）。

| 差异                                                                                                                                                                     | 原因                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| 卡片内容比示意图右移 1–2 格（S `┃  ▶ 林晓`，示意 `┃ ▶ 林晓`）                                                                                                            | nsh 限制：原生边框要求至少 1 列内边距（见 02）                                                                          |
| S / M 紧凑卡的第二行是 `{地区} · {详细地址}`                                                                                                                             | 有意：components.md（AddressCard 紧凑卡）规定 `地区 · 详细地址`；第四波把 S 示意图改成了一致                            |
| L 卡宽 (列 − 4) ÷ 2 = 63（130 列）                                                                                                                                       | 有意：L 内容边距 1 列（responsive.md）；本文件原写 62 已改                                                              |
| 保存失败：服务器故障（5xx、网关错误）与无连接一律显示 `✗ 保存失败，请重试`；能指导用户的服务器文案（字段错误、`地址最多保存 20 条`、`操作太频繁，请稍后再试`）照原文显示 | 有意（第四波修复：之前直接显示 `服务器内部错误`）                                                                       |
