## 行为

- `m` 界面动画开关：开时蒸汽轮换、盘旋字符转动、进度条逐步前进；关时三者全部静止（蒸汽停在第 1 帧，盘旋字符固定为 `⠋`，进度条直接跳到结果）。Toast（提示）`界面动画已开启` / `蒸汽、盘旋字符与进度条恢复动画`；`界面动画已关闭` / `所有画面即时切换`（开启时的副标题为新增，源稿是 `过渡、雷达与进度条恢复缓动`）。设置保存在账号上。
- `o` 鼠标追踪开关：开时悬停移动游标 / 铺悬停底色；关时只有点击有效。Toast（提示）`鼠标追踪已开启` / `悬停即移动高亮`；`鼠标追踪已关闭` / `点击仍然可用`。状态栏 `●` / `○ 鼠标` 同步。
- `q` 退出登录：先打开**退出登录确认**对话框（见下节，U4）；确认后结束会话、解除当前公钥的“记住我”，回到登录页（见 [01-login.md](01-login.md#何时出现)）。
- 推荐按钮：打开该商品详情（源稿固定推荐“波奎特 瑰夏”“涅里 AA 双洗”）。
- 订单：最新在上；本次会话新下的订单状态为 `烘焙中`；只读，不可选中（源稿如此）。订单多于可见行时面板内滚动。

## 退出登录确认

产品决定 U4（[decisions.md](../decisions.md)）：会员按 `q`（任何应用页）或点 `[ q 退出登录 ]` 都先弹出确认对话框，不直接退出。访客按 `q` 无效。

- 键：`q` 或 `⏎`（焦点在 `退出登录` 上）确认；`Esc` 取消并把焦点还给原处；`Tab` / `Shift+Tab` / `←` `→` 在两个按钮间移动（焦点在 `取消` 上时 `⏎` = 取消）；`?` 与其他键无效（K24）。鼠标单击按钮同按键。
- 确认后：按钮换成 `⠹ 正在退出…`（新增，1 行），除 `?` 外按键无效；请求成功或失败（网络错误）都回到登录页并弹 Toast `已退出登录` / `按 ⏎ 重新登录`——本地会话无论如何都清掉。
- 底栏（新增）：`‹q› 确认退出  ‹⏎› 确认  ‹Tab› 切换  ‹Esc› 取消`；S 同左。
- S 断点：宽 min(56, 列数 − 4)，文字超出时 `…`；矮屏同样 11 行。
