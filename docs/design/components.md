# 组件

设计系统的 20 个组件（`raw/design-system/components/*/README.md`），各对应 `apps/tui/src/ui/` 下的一个文件。示意图记号见 [README](README.md#示意图记号)；颜色与属性见 [tokens.md](tokens.md)。所有尺寸单位是格（列 × 行）。

通用规则：

- 每个可操作的文字以快捷键开头（`⏎ 查看详情`、`a 加入购物车`）；按钮、底栏提示和帮助由同一张命令表驱动（见 [keymap.md](keymap.md)）。
- 键盘焦点：有框控件改为 `acc` 粗框；无框控件（按钮、Chip、Toggle）在焦点时加**粗体 + 下划线**，并在控件左侧一格画 `acc` 色 `›`（左侧没有空格时省略 `›`，只保留属性）。
- 悬停（仅在“鼠标追踪”开启时）：行和卡片铺 `hover` 底色带；单色下加下划线。悬停从不改变选择以外的状态。
- 禁用：`disabled` 色 + 删除线或说明文字；禁用控件仍可获得焦点，⏎ 时在状态栏位置不提示，什么都不做。

## Wordmark

**用途**：品牌字标。两种：登录页 5 行块字，顶栏单行 `◆ROAST/TTY`。

```text
████   ███   ███   ████ █████     █ █████ █████ █   █
█   █ █   █ █   █ █       █      █    █     █    █ █
████  █   █ █████  ███    █     █     █     █     █
█  █  █   █ █   █     █   █    █      █     █     █
█   █  ███  █   █ ████    █   █       █     █     █
```

- 块字 53×5：前 30 列“ROAST ”用 `acc` 粗体，后 23 列“/TTY”用 `fg` 粗体；字母 5×5，字母间 1 列空格（源稿 `GLYPH`/`LOGO`）。
- 单行字标 10×1：`◆ROAST/TTY`，`◆` `acc`、`/` `mute`、其余 `fg` 粗体；顶栏里它是回到“选购”的按钮（等同 `1`）。
- **矮屏（<32 行）**：登录页块字换成单行字标（见 [responsive.md](responsive.md)）。
- 消费方提供：无（固定内容）。不要换掉 `◆`，不要改两段配色。

## Window

**用途**：整屏框架。终端本身就是窗口，所以不再画外框和圆点（D2）。

```text
 roast@tty: ~/shop — 160×50        ! 演示环境 · 不是真实商店        ● 公钥已识别 · 21:04
```

- **系统行**（第 0 行，`surface` 底）：左 `roast@tty: ~/shop — {列}×{行}`（`mute`，实时尺寸；宽度 <100 列时省略）；居中 `! 演示环境 · 不是真实商店`（`acc` 粗体，单色粗体）；右 `● 公钥已识别`（`acc2`）或 `○ 未提供公钥`（`mute`）+ ` · HH:MM`（服务器时间，`mute`）。
- **顶栏**：XL/L/M 4 行（字标、NavTabs、3 行搜索框、账户；第 4 行下边线），S 2 行（见 NavTabs）。登录页没有顶栏。
- **内容区**：XL 左右边距 2 列、上下各 1 空行；L/M 边距 1 列；S 0 列。
- **状态栏**：最底 1 行（见 StatusBar）。
- 遮罩层（对话框、帮助）从第 1 行开始盖住，系统行始终可见。
- 消费方提供：当前页面、模式名、底栏提示、是否有公钥、时钟。

## StatusBar

**用途**：最底 1 行的模式行（像 vim / tmux）。

```text
▐ 选购 BROWSE ▌ ‹↑↓› 移动  ‹⏎› 详情  ‹a› 加入  ‹f› 产区  ‹r› 烘焙  ‹s› 排序  ‹/› 搜索            ● 鼠标   购物车 ¥426.00   ‹?› 帮助
```

- 模式块：实心药丸 `▐ 中文 ENGLISH ▌`（`acc` 底、`ink` 粗体；英文部分不加粗）；宽度随文字变化。模式表见 [keymap.md](keymap.md#模式名)。
- 提示：每条 `‹键› 文字`，条目之间 2 列；文字 `mute`。**每条都可点击**，点击等同按键。
- 右侧：`● 鼠标`（追踪开 `acc2` `●`，关 `mute` `○`）、`购物车 ¥{合计}`（数字 `fg`）、`‹?› 帮助`，组间 3 列，右边距 1 列。
- S（<100 列）：右侧只保留 `¥{合计}`；提示限 4 条 + `‹?› 帮助`；当提示与右侧之间不足 2 列时，右侧整体隐藏。
- 消费方提供：模式、提示列表 `{key, label, command}`、鼠标追踪状态、购物车合计。

## NavTabs

**用途**：顶栏主导航，按 `1`–`4` 跳转。顺序固定：`1 选购 · 2 购物车 · 3 地址本 · 4 我的`；详情页属于“选购”。

```text
  ◆ROAST/TTY              ‹1› 选购   ‹2› 购物车 ▐3▌  ‹3› 地址本     ‹4› 我的
───────────────────────━━━━━━━━━━━━━━────────────────────────────────────────────
```

- XL：每个标签 14 列宽（116 px），从第 23 列起；标签文字在顶栏第 2 行居中。当前标签 `fg` 粗体，其余 `mute`。下划线画在顶栏第 4 行（下边线）上：当前标签那 14 列由 `─` 换成 `acc` 色 `━`。
- 购物车数量胶囊：`▐3▌`（`acc` 底、`ink` 粗体），数量 = 所有行的件数之和；为 0 时不画。
- S：标签紧排（间隔 2 列），胶囊紧贴文字 `购物车▐3▌`；下划线长度 = 标签文字宽度。
- 不做滑动动画（D11）。
- 消费方提供：标签 `{key, label, badge?}`、当前索引、跳转命令。

## Panel

**用途**：基本容器，标题压在上边框上。

```text
╭─ 筛选 FILTER ───────────╮
│                         │
│ 产区                ‹f› │
│ ◉ 全部                8 │
╰─────────────────────────╯
```

- 圆角细框 `line` 色；标题从左上角后第 2 列开始，写成 `─ 标题 ─`（标题前后各 1 个空格），`acc` 粗体。标题格式“中文 ENGLISH”或带计数“购物车 · 3 件”“商品列表 · 8 款 · 推荐”。成功回执的标题用 `acc2`。
- 无标题面板（详情左栏）只画框。
- 内边距：顶部 1 空行（标题行之下），左右 1–3 列（各画面规格给出）。
- `.t-panel--card`（登录、回执、访客提示）：同样的圆角框，居中放置，左右内边距 4 列。
- **Inset**（凹陷信息块：收货地址、冲煮建议、统计格）：内部的圆角细框，3 行起，左右内边距 2 列。
- **Heading** 小节标题：`── 豆子档案`，`acc` 粗体，下方紧跟内容（不空行）。
- **Rule**：合计前的虚线 `╌╌╌`（`line`）；回执里用 `line-strong`。
- 面板之间不画阴影、不画左侧色条。
- 消费方提供：标题、内容、位置与尺寸（由页面栅格给出）。

## Button

**用途**：一切操作。文字永远以快捷键开头。高度 1 行。

```text
▐ ⏎ 查看详情 ▌  [ a 快速加入 ]  [ b 立即购买 ]  [ q 退出登录 ]  ╎ 已删除 慧兰 粉红波旁 · u 撤销 ╎  3 更换 →
```

| 变体            | 画法                                      | 颜色 / 属性                                      |
| --------------- | ----------------------------------------- | ------------------------------------------------ |
| primary         | `▐ 文字 ▌`，需要撑满时文字居中            | `acc` 填充、`ink` 粗体；单色反显                 |
| default（次级） | `[ 文字 ]`                                | 括号 `line`、文字 `fg`                           |
| outline         | `[ 文字 ]`                                | 括号与文字 `acc`，文字粗体（只用于“b 立即购买”） |
| danger          | `[ 文字 ]`                                | 括号 `danger-line`、文字 `danger`                |
| undo            | `╎ 文字 ╎`                                | 虚线 `danger-line`、文字 `danger`                |
| green           | `[ 文字 → ]`                              | 括号 `acc2-line`、文字 `acc2`（按画像推荐）      |
| link            | `文字 →`                                  | `acc`，无括号（“3 更换 →”）                      |
| add             | 虚线框卡片 `╭╌╮`，居中 `+`（`acc`）与说明 | 见 AddressCard                                   |

- 状态：焦点 = 左侧 `›` + 粗体下划线（primary 反显本身已明显，仍加 `›`）；禁用 = `disabled` + 删除线；提交中 = 原位替换成 2 行加载块（见 Meter），按钮所在区域高度不变时向下占用下一空行。
- 不要一屏放两个 primary；不要用图标代替按键前缀。
- 消费方提供：文字（含按键前缀）、命令、可选宽度（撑满时）。

## Kbd

**用途**：显示一个按键。

```text
‹a›  ‹⏎›  ‹↑↓›  ‹space›  ‹Esc›  ‹  1 – 4  ›
```

- 标准：键名两侧各 1 格空白，整体铺 `kbd-bg` 底，键名 `fg` 粗体（示意图里的 `‹` `›` 就是这两格空白）。16 色 / 单色：反显。
- 状态栏里同样画法（源稿的 flat 变体与标准在终端里无差别）。
- 宽键帽（帮助）：固定 11 格，键名居中。
- 在主按钮里（`登录 ⏎`）：不画底，直接 `ink` 粗体，属于药丸内容。
- 键名写法：单字母小写，数字，符号 `/ ? ⏎ ← → ↑↓`，词 `space Esc Tab`；组合用空格或 `/`：`↑↓ / j k`。
- 消费方提供：键名。

## Input

**用途**：文本输入。三种：提示符输入框（登录）、普通输入框（对话框、优惠码）、搜索框（顶栏）。

```text
用户名                                          ╭─ 优惠码 ─────────────────╮
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓   │ 试试 TTY10               │
┃ › 林晓                                    ┃   ╰──────────────────────────╯
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

- 3 行：圆角细框 `line`；**聚焦时换粗框 `┏━┓` 且 `acc` 色**（字形 + 颜色）。内容从框内第 2 列开始。
- 标签：默认在框上方一行（`mute`）；**矮屏（<32 行）或 S 断点**改为压在上边框里 `╭─ 标签 ─`（省 2 行），聚焦时同样换粗框。
- 提示符输入框：内容前 `› `（未聚焦 `mute`、聚焦 `acc` 粗体）；终端不闪烁提示符，光标用终端自己的竖线光标（nsh 文本框行为）。
- 密码：每个字符显示为 `•`。
- 优惠码：输入自动转大写（源稿 `text-transform: uppercase`，提交时 `trim().toUpperCase()`）。
- 搜索框：XL/L/M 3 行框，内含 `‹/›` 键帽与占位“搜索豆子、产区或风味…”；有内容时右端出现 `✕`（`mute`，可点击清除）。S 只显示 `‹/› 搜索`，按 `/` 时顶栏第 1 行整行变成输入框。
- 占位文字 `placeholder` 色；输入文字 `fg`。
- 校验信息：输入组下方一行 `✗ 原因`（`danger`，单色粗体），见 [copy.md](copy.md#校验错误)。
- 两列表单（收货人 / 手机号）之间 2 列。
- 消费方提供：标签、值、占位、是否密码、是否大写、焦点、错误。

## Toggle

**用途**：勾选、开关、单选。都用字形表示状态。

```text
[✓] 记住我 30 天          界面动画 m                       [ ■ 开 ]
[ ] 设为默认              鼠标追踪 o                       [ □ 关 ]
◉ 全部                8
○ 埃塞俄比亚          1
```

- 勾选：`[✓]` / `[ ]` + 空格 + 文字。框字形选中 `acc` 粗体、未选 `mute`；文字 `soft`。禁用：整行 `disabled`，下一行给出原因（如“记住我”无公钥时）。
- 开关：右对齐的 `[ ■ 开 ]` / `[ □ 关 ]`（8 列）；开 = `acc` 括号与文字，关 = `line` 括号 + `mute` 文字。左侧标题 `fg` + 空格 + `mute` 快捷键字母，下一行 `mute` 说明。
- 单选：`◉` / `○` + 名称，选中行 `acc` 文字并铺 `selection` 底。
- 不要用 ✔ 或 emoji；不要只靠颜色。
- 消费方提供：标签、状态、命令、（开关）快捷键字母与说明、（禁用）原因。

## Chip

**用途**：一组互斥选项中的一个。高度 1 行，选项之间 1 列。

```text
▐全部▌ [浅] [中] [深]                      ← 烘焙度（分段）
▐  推荐   ▌ [ 价格 ↑  ]                     ← 排序（2×2 网格，每格 11 列）
[ 100g ] ▐ 250g ▌ [ 500g ] [ 1kg  ]         ← SKU 重量，下一行是价格备注
  ¥53      ¥118     ¥224     缺货
▐整豆▌ [手冲] [意式] [法压] [冷萃]          ← SKU 研磨
▐ 标准袋 ▌ [ 礼盒装 +¥20 ]                  ← SKU 包装
标签  ▐ 家 ▌ [ 公司 ] [ 学校 ]              ← 对话框标签选择
```

| 源稿类      | 终端                                                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `.t-filter` | 见 Toggle 单选（`◉`/`○` 列表，右侧数量 `mute`）                                                                                             |
| `.t-seg`    | 未选 `[文字]`（括号 `line`、文字 `soft`）；选中 `▐文字▌`（`acc` 填充、`ink` 粗体）                                                          |
| `.t-opt`    | 同上；重量 Chip 8 列，下一行居中写价格备注（选中项 `acc`，其余 `mute`）；不可选：文字 `disabled` + 删除线，备注写“缺货”，键盘与鼠标都跳过它 |
| `.t-pick`   | 同 `.t-seg`，左右各 1 格内边距                                                                                                              |

- SKU 组：组名一行（`mute`），**键盘焦点所在组**在组名前画 `acc` `›`、组名改 `fg` 粗体，并在行尾显示 `← → 切换`（数量组为 `← → 增减`）。选项比组名缩进 2 列。
- 区块标题（筛选）：`mute` 文字，同一行右端放该区块的键帽 `‹f›` `‹r›` `‹s›`。
- 消费方提供：选项、当前值、选择命令；SKU 还要组名、焦点、每项的备注与可用性。

## Stepper

**用途**：数量加减。高度 1 行。

```text
[ − │ 1 │ + ]  现货 26 份 · 每周二、五烘焙     ← 详情（13 列）
[ −   1   + ]                                  ← 购物车行（13 列）
```

- `−` 是 U+2212；`−` `+` 可点击；数字 `fg` 粗体。到下限 1 时 `−` 变 `disabled`，到上限 min(9, 库存) 时 `+` 变 `disabled`。
- 库存说明：库存 >10 `acc2`“现货 {n} 份 · 每周二、五烘焙”；≤10 `acc`“仅剩 {n} 份 · 售完即止”；为 0 时“暂时缺货”（`danger`，并禁用加购，见 [keymap.md](keymap.md#源稿冲突与处理)）。
- 键盘：详情页焦点在“数量”组时 `← →` 增减，任何时候 `+`/`=`、`-`/`_` 增减；购物车里 `← →`、`+ −`、`h l` 增减当前行。
- 消费方提供：数量、上下限、命令、可选库存说明。


| 源稿类            | 终端                       | 颜色                                        |
| ----------------- | -------------------------- | ------------------------------------------- |
| `.t-tag`          | `[文字]`                   | 括号 `acc2-line`、文字 `acc2`               |
| `.t-tag--note`    | `#文字`，相邻两个之间 2 列 | `acc2`                                      |
| `.t-tag--solid`   | `▐文字▌`                   | `acc2` 填充、`ink` 粗体                     |
| `.t-tag--default` | `▐默认▌`                   | `acc` 填充、`ink` 粗体                      |

- 消费方提供：文字（2–4 个汉字为宜）。不要用红色标签做促销，不要放 emoji。

## DataRow

**用途**：表格式列表：商品列表、购物车、订单。

```text
     名称                           产区         处理法     烘焙     价格 /250g
├────────────────────────────────────────────────────────────────────────────────┤
  ▶  耶加雪菲 孔加 [新产季]         埃塞俄比亚   水洗       ●○○○○           ¥98
     Ethiopia · Yirgacheffe Konga G1

     慧兰 粉红波旁 [店长推荐]       哥伦比亚     水洗       ●●○○○          ¥118
```

- 表头 1 行（`mute`），下面一条 `├──┤` 分隔，与面板边框相接。金额列右对齐。
- 商品行 3 行：第 1 行名称（粗体）+ 可选 Tag + 各列，第 2 行英文副标题（`mute`，单行，超出用 `…`），第 3 行空。
- **当前行**：第 1 列 `▶`（`acc`），名称改 `acc`，两行文字都铺 `selection` 底色带（第 3 行不铺）；单色下这两行反显。
- 烘焙度 `●●○○○`（5 格，`acc`）。价格 `¥` + 整数，粗体。
- 购物车行（3 行）：游标列 `▶`、勾选 `[✓]`、名称 / 副标题“产地 · 烘焙度”、规格“250g · 手冲 · 标准袋”、单价、Stepper、小计（两位小数，粗体）、`✕` 删除（`mute`，可点击）。未勾选的行名称与小计改 `mute`。
- 订单行（2 行，不可选）：单行文字 + 下一行 `┈` 分隔（`line-row`）；状态 `● 运输中` / `● 烘焙中`（`acc`）、`● 已签收`（`acc2`）。
- 交互：`↑↓`/`j k` 移动游标；单击选中，双击或 ⏎ 打开；鼠标追踪开启时悬停也移动游标（购物车、地址本）或只铺悬停底色（商品列表，同源稿）。列表超出高度时滚动，右侧内边缘画 1 格滚动条 `│`/`┃`。
- 不做逐行进场动画（D11）。
- 消费方提供：列定义（宽度、对齐）、行数据、当前索引、命令。

## AddressCard

**用途**：地址本里的一张地址卡。


## Leader

**用途**：键 ┈┈┈ 值，用于豆子档案与订单回执。

## Radar

**用途**：六维风味雷达。轴顺序固定：酸度（上）、甜感、醇厚、苦度（下）、余韵、香气，顺时针（`LABELS`）。

```text
          酸度
          ⣠⠴⠚⠦⣄
      ⢀⡤⠖⠉⢀⡠⣤⢄⡀⠉⠲⢤⡀
香气 ⡎⢡⡤⠒⠋⠁   ⠈⠙⠒⠤⣌⢱ 甜感
     ⡇⢸⠁         ⢰⠋⢸
     ⡇⢸         ⢠⠃ ⢸
     ⡇⢸ ⣀⣠⠤⠔⠶⠒⠒⠤⣯  ⢸
余韵 ⢇⡘⠋          ⢀⡸ 醇厚
      ⠈⠓⠦⣀     ⣀⠴⠚⠁
          ⠙⠲⠤⠖⠋
          苦度
```

- **盲文点阵**（每格 2×4 点，点为正方形 4×4 px）：整块 25×11 格；中间 15×9 格的点阵画布，中心点 (14.5, 17.5)、外半径 17 点（源稿 220×200 px、半径 70 px 的同比例）。
- 只画两样：外圈六边形（`line-strong`）和数据多边形（商品 `acc`、我的口味 `acc2`），顶点处补 2×2 点。源稿的 4 圈内网格与 6 条轴线在盲文分辨率下会糊成一片，**不画**；半透明填充也不画。一个格子里同时有网格点与数据点时取数据色。
- 轴名（`mute`）：酸度在第 0 行居中，苦度在第 10 行居中；香气 / 甜感在第 3 行左右，余韵 / 醇厚在第 7 行左右，与六边形之间留 1 列。
- 数据点坐标：第 i 轴角度 `i×60° − 90°`，半径 `R × 值 / 10`（值钳到 0–10）。
- **回退**：高度 <32 行、或所在栏宽 <25 列时，改画 6 行 Meter（`酸度 ▉▉▉▉▉▉▉░░░  7/10`，条长 10）。终端字体缺盲文时同样回退（盘旋字符也依赖盲文，见开放问题）。
- 无动画（源稿 520 ms 缓动在终端里即时到位）。
- 消费方提供：6 个 0–10 的值、配色语义（商品 / 我）、无障碍标签“{商品名} 风味雷达：酸度 8，甜感 7，…”。

## EmptyState

```text
  ┌────────────┐
```

## 实现与规格的差异（nsh 0.6.1）

实现在 `apps/tui/src/ui/`（每个组件一个文件，组件库见 `ui/gallery.rs`）。下面是 nsh 0.6.1 的终端绘制做不到、只能取最接近画法的地方；其余一律按上文。颜色怎样穿过 nsh 的 ANSI 映射见 [tokens.md](tokens.md#终端载体carrier)。

| 组件                           | 规格                                    | 实现                                                                                                                                                                                    | 原因                                                                                                                                    |
| ------------------------------ | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 全部有框组件                   | `╭─╮` `┏━┓` `╔═╗` `╭╌╮`，标题压在上边框 | Panel 仍用 nsh 自己的细圆角边框（标题是压在边框上的兄弟视图）；粗框、双线框、虚线框、卡片、凹陷块、输入框、Toast、对话框、地址卡都是用字形画的框（`ui/frame.rs`），标题直接写在上边框里 | nsh 只画单线边框，且只在它的终端布局认为是“卡片”的盒子上画                                                                              |
| 内边距与间距                   | 各组件给出的格数                        | 精确的格数用空白占位视图实现（`layout::hspace` / `vspace`）                                                                                                                             | nsh 的终端布局把水平内边距折成至多 2 列（文字盒至多 1 列）、24pt 以下的纵向内边距与 16pt 以下的纵向间距记 0 行，有框盒子里的间距记 0 行 |
| Window / Dialog / Toast / 卡片 | `surface` 底色                          | 站在 `bg` 上；系统行与状态栏（1 行）仍铺 `surface`                                                                                                                                      | nsh 只给 3 行以下的盒子铺底色；逐行铺色在单色下会把整块反显                                                                             |
| AddressCard                    | 当前卡 `surface-selected` 底            | 不铺底，粗框 `acc` + `▶` 区分                                                                                                                                                           | 同上                                                                                                                                    |
| Dialog                         | 背景整体加暗淡属性                      | 背景照原样画；对话框靠双线框与状态栏模式（`编辑 INSERT`、`确认 CONFIRM`）表明                                                                                                           | nsh 的终端绘制不画遮罩，也不让应用改别处的属性                                                                                          |

| Dialog                         | 尺寸固定                                | 宽 min(规格, 列 − 4)，高 min(规格, 行 − 2)                                                                                                                                              | 小终端里放得下                                                                                                                          |
| Toast                          | S 断点“贴在状态栏上方”                  | 所有断点都是下缘在状态栏上方隔一空行（与 XL 相同），右缘 XL/L/M 距屏幕 2 列、S 1 列                                                                                                     | 规格未给 S 的行号，取 XL 的规则                                                                                                         |
| Input                          | 聚焦只换粗框                            | 粗框 `acc` 之外，nsh 还给获得焦点的输入框加下划线，并在该行画它的焦点色带（钉色换成 `selection` 底）                                                                                    | 焦点标记由 nsh 的文本框自己画                                                                                                           |
| Input                          | 占位文字 `placeholder` 色               | 占位文字为 `mute`                                                                                                                                                                       | nsh 把占位文字一律画成暗淡的默认前景                                                                                                    |
| Input                          | 在输入框里按 Esc / Tab / ⏎              | 命令表里这几个键要用 `KeyOptions { when: When::Always, .. }` 绑定（组件库如此）                                                                                                         | nsh 默认把输入框能用的键（所有非字符键）留给输入框                                                                                      |
| Button / Toggle / Chip         | 焦点时左侧一格画 `›`                    | `›` 是叠在左侧一格上的绝对定位文字；左侧没有那一格时被裁掉（规格允许）                                                                                                                  | —                                                                                                                                       |
