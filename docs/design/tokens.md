# Token：颜色、字样、间距

来源：`raw/design-system/tokens.json` / `tokens.css`，终端主题文件 `apps/tui/theme.json`（shadcn `cssVars.dark`）。只有一个主题：深色 Terminal。

## 色深与回退原则

- 真彩（`COLORTERM=truecolor`）：宿主把主题 token“钉色”为下表的十六进制值。
- 256 色：取最接近的 xterm-256 色；半透明 token 用下表给出的“混合后实色”。
- 16 色：用下表“16 色”一列；面板不铺底色，靠边框和间距分层。
- 单色（`NO_COLOR` 或 `COFFEE_COLORS=mono`）：只用属性：**粗体**、**暗淡**、**反显**、**下划线**、**删除线**。
- **任何状态都必须同时有字形和属性**，颜色只是第三重提示：选中 = `▶` / `▐▌` / `◉` / 粗框 + 粗体或反显；错误 = `✗` / `!` + 粗体；成功 = `✓`；禁用 = 暗淡 + 删除线或说明文字；开关 = `■ 开` / `□ 关`；勾选 = `[✓]` / `[ ]`。

### 语义 → 属性速查

| 语义                | 真彩 / 256 / 16 色                   | 单色           | 必须同时出现的字形     |
| ------------------- | ------------------------------------ | -------------- | ---------------------- |
| 当前行（游标）      | `selection` 底色带 + 名称 `acc` 粗体 | 整行反显       | `▶`                    |
| 键盘焦点（控件）    | `acc` 粗框 / `acc` 文字 + 粗体       | 粗体 + 下划线  | 粗框 `┏━┓`，或行首 `›` |
| 选中（单选 / 分段） | `acc` 填充 + `ink` 粗体              | 反显           | `▐ ▌`、`◉`             |
| 勾选                | `acc` 字形                           | 粗体           | `[✓]` / `[ ]`          |
| 开关                | 开 `acc`、关 `mute`                  | 开粗体、关暗淡 | `■ 开` / `□ 关`        |
| 禁用                | `disabled` + 删除线                  | 暗淡 + 删除线  | 说明文字（如“缺货”）   |
| 错误                | `danger`                             | 粗体           | `✗ ` 前缀              |
| 成功                | `acc2`                               | 正常           | `✓`                    |
| 警告 / 演示提示     | `acc` 粗体                           | 粗体           | `! ` 前缀              |

## 间距、尺寸

换算规则见 [README](README.md#格子换算)。横向按 8 px / 列，纵向按 16 px / 行，.5 向下取。

| token      | px  | 横向（列）                   | 纵向（行） | 终端里最常见的位置                       |
| ---------- | --- | ---------------------------- | ---------- | ---------------------------------------- |
| `space-2`  | 2   | 0                            | 0          | —                                        |
| `space-4`  | 4   | 0（相邻 Chip 之间仍留 1 列） | 0          | Chip 之间                                |
| `space-6`  | 6   | 1                            | 0          | 键帽与文字                               |
| `space-8`  | 8   | 1                            | 0          | 按钮之间、规格 Chip 之间                 |
| `space-10` | 10  | 1                            | 1          | 成对按钮之间、面板左右内边距（列表侧栏） |
| `space-12` | 12  | 1（两列表单之间用 2）        | 1          | 面板内小节                               |
| `space-14` | 14  | 2                            | 1          | 面板之间的栅格间距、面板标题左缩进       |
| `space-16` | 16  | 2                            | 1          | 表头内边距、主要分组之间                 |
| `space-18` | 18  | 2                            | 1          | 顶栏元素之间                             |
| `space-20` | 20  | 2                            | 1          | 内容区左右边距、面板内边距               |
| `space-24` | 24  | 3                            | 1          | 面板顶部内边距                           |
| `space-32` | 32  | 4                            | 2          | 独立卡片（登录、回执、对话框）左右内边距 |
