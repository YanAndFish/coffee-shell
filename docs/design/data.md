## 计价

全部在服务端计算（单一事务里重新计价、扣库存、生成订单号）。

1. **单价** = round(基价 × 重量系数) + 包装加价。round 是“.5 进位”（JS `Math.round`）。
2. **行金额** = 单价 × 数量；数量 1–9 且不超过库存。
3. **小计** = Σ 已勾选行的行金额（未勾选的行不参与）。
4. **优惠**：优惠码 `TTY10`（去首尾空格、不区分大小写）= round(小计 × 10%)；其他码无效：`✗ 优惠码无效或已过期`；空码 = 不使用。
5. **运费**：小计为 0，或（小计 − 优惠）≥ ¥199 时为 0（`包邮`），否则 ¥12。
6. **合计** = 小计 − 优惠 + 运费。
7. **免运费进度** = min(100, round((小计 − 优惠) ÷ 199 × 100))%；**差额** = 199 − (小计 − 优惠)。
8. **订单号** = `RT` + 年份后两位 + 月（2 位）+ 日（2 位）+ 4 位随机数（1000–9999）。服务端须保证唯一（冲突时重抽）。
9. **预计送达** = 下单时间 + 3 天，显示 `{M} 月 {D} 日`。
10. 下单成功后：已勾选的行从购物车移除，优惠码清空，新订单状态 `烘焙中`，排在订单列表最前。

| 行               | 规格                 | 单价                          | 数量 | 行金额  |

| 慧兰 粉红波旁    | 250g · 手冲 · 标准袋 | round(118 × 1) + 0 = ¥118     | 1    | ¥118.00 |
| 「夜班」意式拼配 | 500g · 意式 · 标准袋 | round(88 × 1.9) + 0 = ¥167    | 1    | ¥167.00 |

小计 ¥426.00；优惠 −¥0.00；426 ≥ 199 → 运费 `包邮`；**合计 ¥426.00**；进度 100%，`已满 ¥199 · 本单包邮`；结算按钮 `c 结算 3 件`。

### 例 2：一袋 250g 耶加雪菲 + `TTY10`

单价 round(98 × 1) + 0 = ¥98；小计 ¥98.00；优惠 round(98 × 0.1) = round(9.8) = ¥10 → `−¥10.00`；98 − 10 = 88 < 199 → 运费 `¥12.00`；**合计 ¥100.00**；进度 round(88 ÷ 199 × 100) = 44%；`再买 ¥111 即可包邮`。

### 例 3：检验示例订单

源稿“最近订单”的三个金额都符合上面的规则：`RT2611180031` = 粉红波旁 250g ¥118 + 夜班 500g ¥167 = ¥285（包邮）；`RT2611060117` = 耶加雪菲 250g × 2 = ¥196 < 199 → +¥12 = ¥208；`RT2610210088` = 瑰夏 100g ¥121 + ¥12 = ¥133。
