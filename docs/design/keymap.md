# 快捷键

由源稿 `HELP`、`HINTS`、`handleKey` / `keyList` / `keyDetail` / `keyCart` / `keyAddr` / `keyProfile` / `onKey` 对照整理。实现时用**一张命令表**（`Command { id, key, label, scope, footer_rank, enabled, run }`）同时驱动按键、按钮文字、底栏提示和帮助，避免四处不一致。

## 处理顺序

按下一个键时，按下面的顺序找处理者，找到即停：

1. **帮助打开**：只认 `?`、`Esc`、`q`（都是关闭帮助）；其他键忽略。
2. **对话框打开**：只认对话框自己的键（见下）；`?` 不打开帮助。
3. **焦点在文本输入框里**：可打印字符进入输入；`⏎` 执行该框的提交动作（登录 / 注册提交、对话框保存、优惠码应用、搜索框离开）；`Esc` 离开输入框（对话框里是取消）；`Tab` / `Shift+Tab` 移动焦点。**字母快捷键在输入框里一律不生效。**
4. **提交中**（登录 / 注册 / 结算 / 保存地址）：只认 `?`。
5. `?`：打开帮助。
6. 登录页：登录页自己的键（见下），不认 `1`–`4`、`/`、`q`。
7. 应用页的全局键：`1`–`4`、`/`、`q`。
8. 当前画面的键。

`Ctrl`、`Alt`、`Cmd` 组合键不触发任何快捷键（源稿 `onKey`），只有宿主的 `Ctrl+C` 例外。

## 全局键（应用页）

| 键                  | 作用                                     | 说明                                           |
| ------------------- | ---------------------------------------- | ---------------------------------------------- |
| `1` `2` `3` `4`     | 选购 / 购物车 / 地址本 / 我的            | 详情页属于“选购”                               |
| `/`                 | 跳到选购并聚焦搜索框                     |                                                |
| `?`                 | 打开 / 关闭帮助                          |                                                |
| `q`                 | 退出登录（先确认）                       | 仅会员，打开确认对话框；访客按下无效（K3、U4） |
| `Esc`               | 返回 / 清除 / 关闭（各页含义不同，见下） |                                                |
| `Tab` `Shift+Tab`   | 按视觉顺序在控件之间移动焦点             | nsh 默认行为（K18）                            |
| `PageUp` `PageDown` | 滚动当前可滚动区域                       | nsh 默认行为                                   |
| `Ctrl+C` 连按两次   | 断开 SSH 连接                            | 宿主实现（新增）                               |

鼠标（可选，nsh 鼠标以格为精度）：单击选中 / 按下，双击打开，悬停在“鼠标追踪”开启时移动游标或铺悬停底色，底栏提示可以点击。

## 源稿冲突与处理

| #   | 源稿里的情况                                                                                                                               | 处理（本规格）                                                                             |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| K1  | 登录页初始焦点在窗口上，`Tab` 只会聚焦账号框（不循环）；字母键直接是快捷键（`g` = 访客）。真实登录时用户名为空，用户开始打字就可能误触 `g` | 初始焦点放在用户名框；`Tab` 在 6 个控件间循环；`g`、`?` 只在无焦点时有效；`Esc` 离开输入框 |
| K2  | 登录提交中 `⏎` 被忽略，但 `g` 仍可切到访客                                                                                                 | 提交中除 `?` 外全部忽略                                                                    |
| K3  | `q` 是全局退出登录；访客按 `q` 也会“退出登录”并提示 `已退出登录`；`q` 在多数 TUI 里是“退出程序”，易误按                                    | `q` 只对会员有效；访客无效。会员按下先弹确认对话框，`q` / `⏎` 确认（U4、P-ui-1）           |
| K4  | 购物车里 `a` 是“全选”（界面键帽上写着），帮助里 `a` 只写“加入购物车”，购物车底栏也没有 `a`                                                 | 保留两种含义（按画面区分）；帮助“购物车”组加 `a 全选 / 全不选`                             |
| K5  | 删除键：购物车认 `x` `d` `Delete`、底栏写 `x`；地址本认 `d` `x`、底栏与按钮写 `d`；帮助只写 `x`                                            | 两页都认 `x` `d`（购物车另认 `Delete`）；各页底栏保留源稿写法；帮助写 `x d`                |
| K6  | 结算提交中只屏蔽了购物车页自己的键，`1`–`4`、`/`、`q` 仍会离开页面                                                                         | 提交中除 `?` 外全部忽略（真实请求不能半途丢下）                                            |
| K7  | 访客结算被送去登录，登录成功后 `finishLogin` 一律去“选购”                                                                                  | 记住来源，登录后回到购物车                                                                 |
| K8  | 帮助说 `Esc` = “返回上一级 · 关闭弹窗”，但列表页 `Esc` 是清除筛选，地址本 `Esc` 去购物车，购物车 `Esc` 去选购                              | 各页按源稿实现（见上表）；帮助文字不改                                                     |
| K9  | 库存为 0 时只显示“暂时缺货”，数量仍是 1，`a` `b` 照样能加购                                                                                | 库存为 0 时禁用 `a` `b` 与两个按钮；服务端同样拒绝                                         |
| K10 | 编辑地址时电话带入的是打码字符串 `138 **** 5521`，保存时 `maskPhone` 不认，原号码丢失                                                      | 对话框显示完整号码；只在卡片上打码；服务端存完整号码                                       |
| K11 | 地址对话框里标签与“设为默认”只能用鼠标（或浏览器原生 Tab + 空格）                                                                          | 定义焦点顺序；标签行 `← →`，“设为默认”上 `space`                                           |
