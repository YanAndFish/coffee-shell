# 响应式

单位是终端格。设计稿 = XL 的 160×50。断点只看**当前列数**与**当前行数**；终端尺寸变化时立即重排，状态（当前画面、输入内容、游标、滚动位置、打开的对话框）全部保留，游标所在项保持可见。

## 断点

| 断点 | 条件                              | 布局要点                                                                                                   |
| ---- | --------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 太小 | 列 < 80 或 行 < 24                | “终端太小”提示页，显示当前与所需尺寸；状态保留，放大后原地恢复（[01-login](screens/01-login.md#终端太小)） |
| S    | 80–99 列                          | 单列；预览隐藏；筛选进对话框；底栏 4 条提示 + `‹?› 帮助`；顶栏 2 行                                        |
| M    | 100–129 列                        | 列表 + 预览；筛选为一行 Chip；详情上下堆叠                                                                 |
| L    | 130–159 列                        | 三栏收窄；详情两栏                                                                                         |
| XL   | ≥ 160 列                          | 设计稿布局；内容最宽 200 列                                                                                |
| 矮屏 | 行 < 32（与上面任一宽度断点叠加） | 单行字标、无咖啡杯与蒸汽、雷达降级为风味条、顶栏 2 行、输入框标签压进边框、列表每项 1 行                   |

第二阶段快照尺寸：160×50（XL）、130×40（L）、100×30（M + 矮屏）、80×24（S + 矮屏）。

## 字符宽度

- 宽度一律用 Unicode East Asian Width 计算：W / F 占 2 格，其余（包括“模糊宽度” A 类：制表符、`·`、`●`、`→`、`×`、`▉`、`…`）占 1 格，等同 Rust `unicode-width` 的 `width()`（非 CJK 版本）。
- 把模糊宽度设为“宽”的终端（部分 CJK 区域设置的 iTerm2、Windows Terminal 选项）会让边框错位——本规格不支持这种设置；可以在帮助或 README 里提示用户关闭“模糊宽度按双宽显示”。
- 盲文（雷达、盘旋字符）与块元素（`▉░▐▌`）需要终端字体支持；常见等宽字体（JetBrains Mono、SF Mono、Menlo、Cascadia、Noto Sans Mono）都有。
- 中文与半角字符混排的列，用显示宽度补齐，不用字符数。截断时不把宽字符劈开，省略号 `…` 占 1 格。
