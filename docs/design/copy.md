# 文案

所有界面文字的唯一来源。未标注的条目逐字取自源稿（`Main.dc.html` 的标记与脚本、设计系统 README）；`（新增）` 是本阶段决策需要、源稿没有的文字；`（改）` 是对源稿文字的修改，旧文字写在说明里。`{…}` 是占位。

## 文案规则

- **语言**：简体中文，口吻简短直接，像店员说话，称“你”。
- **中英双写**：面板标题与模式名写“中文 ENGLISH”，英文全大写：`筛选 FILTER`、`规格 SKU`、`选购 BROWSE`。
- **快捷键前置**：可操作的文字以按键开头，按键小写，`⏎ ← → ↑↓` 用符号：`⏎ 查看详情`、`a 加入购物车`、`Esc 取消`、`space 设为默认`、`1 去挑豆子`。说明行把按键串起来：`Tab 切换输入 · ⏎ 提交 · ? 查看全部快捷键`。
- **分隔符**：`·`（前后各一个空格）连接并列信息：`250g · 手冲 · 标准袋`；`/` 表示层级或选择：`选购 / 埃塞俄比亚 / 耶加雪菲 孔加`、`省 / 市 / 区`；`→` 表示去往：`注册新账号 →`、`3 更换 →`。
- **中西文之间空一格**：`48 小时`、`Lv.3`、`2,000 豆`、`仅剩 6 份`。
- **状态字形代替图标**：`✓` 成功、`✗` 错误、`!` 提示 / 演示、`●/○` 开关与烘焙度、`◉/○` 单选、`[✓]/[ ]` 勾选、`■ 开/□ 关` 开关、`▶` 当前项、`›` 提示符、`──` 小节、`◆` 品牌、`∅` 空。不用 emoji。
- **错误**：以 `✗ ` 开头写清原因。**Toast**：标题说发生了什么（4–8 字），副标题给细节或下一步按键。
- **截断**：单行放不下时在末尾用 `…`（1 格），不劈开宽字符；价格、数量、按键永不截断。

### 数字格式

| 场合                                            | 格式                      | 例                    |
| ----------------------------------------------- | ------------------------- | --------------------- |
| 列表价、预览起售价、单价、重量备注、购物车单价  | `¥` + 整数                | `¥98`、`¥118`         |
| SKU 合计、购物车小计 / 合计、状态栏、回执、订单 | `¥` + 两位小数            | `¥118.00`、`¥426.00`  |
| 优惠                                            | `−¥` + 两位小数（U+2212） | `−¥10.00`、`−¥0.00`   |
| 运费                                            | `¥12.00` 或 `包邮`        |                       |
| 免运费差额                                      | `¥` + 整数                | `再买 ¥111 即可包邮`  |
| 会员豆数                                        | 千分位                    | `1,280 / 2,000 豆`    |
| 百分比                                          | 整数 + `%`                | `42%`                 |
| 杯测分                                          | 原值                      | `87.5`、`88 分`       |
| 数量（Toast、回执、单价说明）                   | ` × {n}`（两侧空格）      | `× 1`、`1 × ¥118`     |
| 数量（订单摘要）                                | ` ×{n}`（前空格）         | `250g ×1`             |
| 订单日期                                        | `MM-DD`                   | `11-18`               |
| 送达日期                                        | `{M} 月 {D} 日`（不补零） | `11 月 25 日`         |
| 订单号                                          | `RT` + yymmdd + 4 位      | `RT2611180031`        |
| 冲煮参数                                        | 原文                      | `1:15 · 92°C · 2′30″` |
| 电话（展示）                                    | 前 3 + `****` + 后 4      | `138 **** 5521`       |
