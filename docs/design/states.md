## 动效清单

nsh 在终端里报告“减少动效”：导航与布局过渡一律直接到终态；应用自己的动画照常运行（D11）。本应用只保留三种自绘动画，其余全部即时。

| 源稿动效                       | 源稿参数                                                                         | 终端                                                               |
| ------------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 盘旋字符                       | `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`，每 100 ms 一帧（`tick` 定时器）                                    | **保留**：只在加载块可见时运行，100 ms / 帧                        |
| 加载进度条                     | 每 100 ms 前进 3–10%（登录）/ 3–9%（结算），宽度 120 ms 线性过渡                 | **保留**：按真实请求阶段前进（不伪造进度），每次前进直接跳到新长度 |
| 登录页蒸汽                     | 3 帧轮换，每 400 ms（`floor(tick / 4) % 3`），三缕颜色 `dim` / `steam` / `mute`  | **保留**：只在登录页可见且高度 ≥32 时运行                          |
| 换页                           | opacity 240 ms + translateY 10 px 360 ms                                         | 去掉：即时切换                                                     |
| 列表 / 卡片 / 订单逐项进场     | 每项延迟 32 ms，280 ms 淡入 + 360 ms 位移                                        | 去掉                                                               |
| 列表 / 购物车游标滑动          | translateY 280 ms                                                                | 去掉：游标直接跳到新行                                             |
| 导航下划线滑动                 | translateX 280 ms                                                                | 去掉                                                               |
| 颜色、边框、底色过渡           | 160 ms ease                                                                      | 去掉                                                               |
| 对话框 / Toast 弹出            | opacity 220 ms + scale / translate 320 ms 回弹；遮罩淡入 200 ms；关闭延迟 200 ms | 去掉：即时出现与消失                                               |
| 风味雷达形变                   | 520 ms，缓出三次方                                                               | 去掉：直接画新形状                                                 |
| 计量条宽度（会员等级、免运费） | 800 ms                                                                           | 去掉                                                               |
| 购物车胶囊弹跳                 | scale 1.35，240 ms 回弹                                                          | 去掉                                                               |
| 输入提示符 `›` 闪烁            | 每 500 ms 在 `acc` 与 `steam` 之间切换                                           | 去掉：用终端自己的光标，`›` 常亮 `acc`                             |
| Toast 自动消失                 | 2600 ms                                                                          | 保留（是计时，不是动画）                                           |
| 时钟                           | 每分钟                                                                           | 保留（系统行）                                                     |

“我的 → 界面动画”（`m`）关闭时，三种保留的动画也停下：盘旋字符固定为 `⠋`，蒸汽停在第 1 帧，进度条只在完成时一次画满。

重绘节奏：没有动画运行时只在输入、数据变化、Toast 到期、整分钟时重绘；盘旋字符运行时 10 fps，蒸汽 2.5 fps。
