# Input

三种输入框，全部 `bg` 底（搜索框是 `surface`）、`line` 边框、`radius-6`，聚焦时边框变 `acc`，不画外发光。

## 变体
- **提示符输入框** `.t-prompt`：登录用，44px，左侧一个 800 字重的 `›`。未聚焦 `›` 为 `mute`；聚焦时边框 `acc`，`›` 在 `acc` 与 `steam` 之间闪烁，像终端光标。密码字段字距 0.2em。
- **普通输入框** `.t-input`：对话框与表单用，40px（优惠码 38px，13px，自动大写）。
- **搜索框** `.t-search`：顶栏用，300×36，左侧 `/` 键帽，有内容时右侧出现 `✕` 清除（`mute`）。占位“搜索豆子、产区或风味…”。

## 消费方提供
- 外层 `.t-field`：标签 `.t-field__label`（12px `mute`，在上方，间距 6px）+ 输入框；`<label for>` 必须关联。
- 值、onChange、聚焦状态（提示符输入框需要 `.is-focus` 来切换 `›` 颜色）。
- 校验信息用 `.t-error`：13px `danger`，以 `✗ ` 开头，`role="alert"`，放在字段组下方。

## 规则
- 占位文字 `placeholder`；输入文字 `fg` 14px。
- 两列表单（收货人 / 手机号）间距 12px。
