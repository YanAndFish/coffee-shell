# DataRow

表格式列表：商品列表、购物车、订单。所有可选行共享一个**滑动的游标高亮**，而不是每行各自变色。

## 结构
- 表头 `.t-thead`：与行相同的 grid 列宽，16px 16px 8px 内边距，12px `mute`，下边线 `line`。金额列右对齐。
- 行容器 `.t-rows`：6px 内边距，`position:relative`。
- 游标 `.t-cursor`：绝对定位，`acc-tint-10` 底 + 1px 内描边 `acc-ring-42`，`radius-6`；用 `translateY(index × 行高)` 移动（280ms cubic-bezier(.2,.8,.2,1)）。购物车用 `.t-cursor--cart`（68px，`acc-tint-08` / `acc-ring-38`）。
- 行 `.t-row`：52px（`h-row`），第一列 28px 放 `▶`（仅当前行显示，`acc`），当前行商品名变 `acc`。未选中行悬停 `hover-tint`。
- 名称单元：14px/700 名称 + 可选 Tag，下面 12px `mute` 英文副标题，行高 1.35，单行省略。
- 烘焙度用 5 个 `●○` 圆点（`.t-pips`，`acc` 12px，字距 1px）。价格 700，前缀 `¥`。

## 变体
- 购物车行：44px 勾选列（`[✓]`/`[ ]`），规格写成“250g · 手冲 · 标准袋”，Stepper，小计 800（未勾选的行名称与小计变 `mute`），末列 `✕` 删除（`mute`）。
- 订单行 `.t-order`：46px，不可选，行间分隔 `line-row`，状态写成 `● 运输中`（`acc`）/ `● 已签收`（`acc2`）。

## 交互
↑↓ 或 j k 移动游标；单击选中，双击或 ⏎ 打开；开启“鼠标追踪”时悬停即移动游标。列表进场时行依次淡入上移，每行延迟 32ms。

## 消费方提供
列定义（grid 列宽）、行数据、当前索引、选中 / 打开回调。
