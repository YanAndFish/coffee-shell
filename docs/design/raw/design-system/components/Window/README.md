# Window

整个应用都装在一个假的终端窗口里：圆角 `radius-12`、`line` 边框、`bg` 底色，固定 1280×800。

## 结构（自上而下）
1. **标题栏** `.t-chrome`：高 `h-chrome`（34px），`surface` 底，12px `mute` 文字。左侧三个 11px 圆点（`line-strong`，不做红黄绿），中间是路径 `roast@tty: ~/shop — zsh — 160×48`，右侧是键盘连接状态（`●` 用 `acc2`；未连接时 `○` 用 `mute`，文案“单击窗口以使用键盘”）与时钟。
2. **顶栏** `.t-header`：高 `h-header`（56px），左右 20px，元素间 18px；依次放 Wordmark、NavTabs、弹性空白、300px 搜索框、账户按钮（28px 方块头像 `radius-5`，会员 `acc` 底、访客 `mute` 底，字 `ink`）。登录页没有顶栏。
3. **内容区** `main`：内边距 20px 20px 16px，面板之间用 `space-14` 栅格。
4. **状态栏**：见 StatusBar。

## 消费方提供
- 内容区的页面；当前模式名（中文 + 英文大写）传给状态栏。
- 窗口根元素 `tabIndex=0` 并接收键盘事件；遮罩层（对话框、帮助）从标题栏下方 `top: 34px` 开始盖住。

## 不要
- 不要加系统阴影或玻璃效果；窗口靠边框与底色区分。
