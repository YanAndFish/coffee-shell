# Wordmark

ROAST/TTY 的两种字标：登录页的 5 行 ASCII 块字，和顶栏里的 `◆ROAST/TTY` 文字字标。

## 消费方提供
- 块字：5 行文本，每行两段 `<span>`——“ROAST ”用 `.t-logo__a`（`acc`），“/TTY”用 `.t-logo__b`（`fg`）。字形用 `█` 拼成，每个字母 5×5，字母之间一个空格；`white-space: pre`，16px / 1.08 / 700。外层加 `role="img" aria-label="ROAST/TTY"`。
- 文字字标：`.t-brand`（15px / 800 / 0.04em），`◆` 用 `acc`，斜杠用 `mute`，其余 `fg`。它同时是回首页的按钮。

## 何时用
- 块字只出现在登录页左栏，上方留白、下方接标语（`lede`）。
- 每个应用页面的顶栏左侧固定放文字字标，宽 150px。

## 不要
- 不要把块字改成图片、渐变或描边；它就是等宽字符。
- 不要换掉 `◆` 或改变两段的颜色分配。
