# Meter

数值与进度都画成**分段的块状条**——像终端里的 `█ █ █`，用 repeating-linear-gradient 切出间隙。

## 变体
| 类 | 用途 | 样式 |
|---|---|---|
| `.t-meter` | 风味指标（0–10）、会员等级 | 10px 高，`bg` 槽、`line-soft` 边框、`radius-2`；填充 `acc` 9px 段 + 2px 空隙；宽度变化 800ms cubic-bezier(.2,.8,.2,1) |
| `.t-progress` | 登录 / 结算时的加载进度 | 12px 高，`line` 边框、`radius-3`、2px 内边距；填充 7px 段 + 2px 空隙，120ms linear。登录用 `acc`，结算用 `.t-progress--ok`（`acc2`） |
| `.t-thin` | 免运费进度 | 6px 高，`bg` 槽、`line-soft` 边框；`acc2` 实色填充 |

## 加载状态写法
提交按钮被替换为同高的状态块：上一行“`⠹` 步骤名 …… 62%”（登录：握手 · 建立安全连接 → 校验凭据 → 同步购物车与地址本；结算：校验库存 → 锁定烘焙批次 → 生成订单 → 完成）（盘旋字符 `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` 用 `acc` 循环，百分比 `mute`），下一行 `.t-progress`。加 `role="status"`。

## 消费方提供
百分比或 0–10 的值；风味条一行是 `34px 标签 / 条 / 40px 数值` 的 grid，间距 10px，行距 12px。
