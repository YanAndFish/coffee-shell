# EmptyState

列表为空时的居中提示：一个 ASCII 图形 + 一句话 + 一个带快捷键的出路。

## 写法
- 图形用 `dim`、`aria-hidden`：空购物车画 15px/1.25 的方框杯子（`┌─┐│╮╯└`，杯身写“空  杯”）；无搜索结果用 34px 的 `∅`。
- 一句话 `soft`：“购物车是空的”“没有匹配的豆子”。
- 出路按钮：能直接解决问题的那一步——`1 去挑豆子`（主按钮，40px）、`Esc 清除筛选`（次级，36px）。
- 外层 `.t-empty`：纵向居中，间距 12–14px，默认文字 `mute`。

## 消费方提供
图形（杯子或 ∅）、文案、动作按钮。不要在空状态放插画图片或 emoji。
