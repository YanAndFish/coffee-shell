# Stepper

数量加减器：`−` / 数字 / `+`，用 `line` 边框和 `radius-6` 包成一个整体。

## 变体
- 标准（详情页）：38px 高，按钮 40×36、16px；中间 44px 宽、15px/800，左右各一条 `line` 竖线。
- `.t-stepper--sm`（购物车行）：108×34，按钮 34px、15px；中间自适应、800，无竖线。

## 消费方提供
当前数量、增减回调、按钮的 `aria-label`（“减少数量”“增加 {商品名}”）；可在右侧 14px 处放一行 12px 库存说明（库存 >10 用 `acc2`“现货 42 份 · 每周二、五烘焙”；≤10 用 `acc`“仅剩 6 份 · 售完即止”）。

## 规则
键盘：在详情页 SKU 焦点停在“数量”组时，`← →` 增减；购物车里用 `+` `−`。减号用真正的减号 `−`（U+2212）。
