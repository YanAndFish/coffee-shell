# Chip

一组互斥选项中的一个。四种形态，按位置选用；都是 `<button aria-pressed>`，切换动画 160ms ease。

| 类 | 位置 | 未选 | 选中 |
|---|---|---|---|
| `.t-filter` | 侧栏单选列表（产区） | 28px、透明、`soft` 字，前缀 `○`，右侧数量 `mute` 12px | `acc-tint-12` 底、`acc` 字，前缀 `◉` |
| `.t-seg` | 网格分段（烘焙度 4 列、排序 2 列，间距 4px） | 30px、`line` 边框、`soft` 12px | `acc` 实底、`ink` 字 |
| `.t-opt` | 详情页 SKU（重量 / 研磨 / 包装） | 36px 高、最小宽 58px（研磨）；`--wide` 96px（包装“礼盒装 +¥20”）；`--note` 74×52 带第二行 11px `mute` 价格或“缺货”（重量）；`line` 边框、`fg` 13px | `acc` 边框、`acc-tint-14` 底、`acc` 字；不可选：`disabled` 字 + 删除线 |
| `.t-pick` | 对话框里的标签选择 | 32px、`radius-5`、`soft` 13px | `acc` 实底、`ink` 字 |

## 消费方提供
选项列表、当前值、选择回调；SKU 组还要提供组名、键盘焦点（焦点组的组名前出现 `acc` 色 `›`，组名由 `mute` 变 `fg`，右侧显示 `← → 切换`）和每个选项的价格或备注。

## 规则
- 区块标题 12px `mute`，右侧放该区块的快捷键（`f` `r` `s`）。
- SKU 选项比组名缩进 14px，选项间距 8px。
