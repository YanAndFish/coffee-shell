# Tag

小标签与徽标。默认都是绿色描边：绿色在这个品牌里表示“好消息、属性、成功”，琥珀色留给选中与价格。

| 类 | 用途 | 样式 |
|---|---|---|
| `.t-tag` | 列表里商品名后的属性（新产季、店长推荐、招牌）；地址卡“本单寄往” | 11px/500/16px，`acc2` 字，`acc2-line` 边框，`radius-3`，左右 5–6px |
| `.t-tag--note` | 风味标签，以 `#` 开头（`#茉莉`） | 12px，`radius-4`，1px 8px |
| `.t-tag--solid` | 详情页标题旁的属性 | `acc2` 实底、`ink` 字、12px/800/20px |
| `.t-tag--default` | 默认地址 | `acc` 实底、`ink` 字、11px/800/18px |
| `.t-tag--neutral` | 地址标签（家 / 公司 / 学校） | `line-strong` 边框、`soft` 字 |
| `.t-count` | 导航“购物车”后的件数 | 18px 胶囊 `radius-9`，`acc` 底，`ink` 11px/800；数量变化时 scale 弹一下（240ms cubic-bezier(.3,1.7,.5,1)） |

## 消费方提供
标签文字（2–4 个汉字为宜）；数量胶囊为 0 时不渲染。

## 不要
不要用红色标签做促销；不要在标签里放图标或 emoji。
