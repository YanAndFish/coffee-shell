# Kbd

显示一个按键的小键帽。它是这个品牌最常见的元素：导航、筛选标题、搜索框、按钮、状态栏、帮助面板都在用。

## 变体
- `.t-kbd`：标准键帽。`kbd-bg` 底、`line-strong` 1px 边框且**底边 2px**（立体感）、`radius-4`、11px/16px、最小宽 18px、`fg` 字。
- `.t-kbd--flat`：状态栏里用，底边 1px、`radius-3`、最小宽 16px。
- `.t-kbd--wide`：快捷键帮助里用，最小宽 64px、12px/20px。
- `.t-kbd--on-acc`：放在 `acc` 主按钮里，边框 `ink-kbd-line`、底 `ink-kbd-bg`、字 `ink`。

## 消费方提供
按键文本：单字母小写（`a` `d` `e`）、数字、符号（`/` `?` `⏎` `←` `→` `↑↓`）、或词（`space` `Esc` `Tab`）。组合用空格或 ` / ` 连接：`↑↓ / j k`。

## 规则
- 键帽放在它说明的东西左边，间距 `space-8`（状态栏 6px）。
- 区块标题右侧可放该区块的切换键（筛选里的 `f` `r` `s`）。
