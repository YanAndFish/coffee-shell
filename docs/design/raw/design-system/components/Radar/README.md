# Radar

六维风味雷达，品牌的标志性数据图。轴固定顺序：酸度（上）、甜感、醇厚、苦度（下）、余韵、香气，顺时针。

## 规格
- 画布 220×200，中心 (110,102)，外半径 70。
- 底盘：外圈六边形 `surface-plate` 填充 + `line-strong` 描边；内部 4 圈（半径 56/42/28/14）与 6 条轴线用 `line-soft`，全部 1px。
- 数据：多边形描边 1.5px、圆角连接，顶点 r=3 实心圆。
  - 商品风味：`acc` 描边与顶点、`acc-tint-22` 填充。
  - 个人口味画像：`acc2` 描边与顶点、`acc2-tint-20` 填充。
- 轴名：11px `mute`，居中，放在外圈之外。

## 消费方提供
6 个 0–10 的值，以及完整的 `aria-label`（“{商品名} 风味：酸度 8 甜感 7 …”）。旁边通常配 Meter 风味条或“偏好 / 常买 / 少碰”文字说明。

## 不要
不要加图例或网格数字；不要改变轴的顺序或配色语义（琥珀 = 商品，薄荷 = 我）。
