# Toggle

选择类控件不用原生方框或滑块，而是用终端字符表示状态。都是 `<button aria-pressed>`。

## 三种写法
- **勾选** `.t-check`：`[✓]` / `[ ]` + 文字。框字形选中 `acc`、未选 `mute`，700；文字 13px `soft`。用于保持登录、设为默认、全选、购物车行勾选（行内只显示框，36×36 点击区）。
- **开关** `.t-switch`：76×34 的按钮，文字 `■ 开` / `□ 关`；开为 `acc` 边框与字，关为 `line` 边框 + `mute` 字。左侧放标题（14px，后接 `mute` 快捷键字母）与一行 12px `mute` 说明。
- **单选** 见 Chip 里的 `.t-filter`：`◉` 选中 / `○` 未选。

## 消费方提供
标签文字、`aria-pressed` 状态、切换回调；开关行需提供快捷键字母（如 `m`、`o`）。

## 不要
- 不要用 ✔ 或 emoji；只用 `✓`。
- 不要只靠颜色表达状态——字形本身就要变。
