# AddressCard

地址本里的一张地址卡，两列网格排列（间距 14px），最后一格是虚线“新增收货地址”占位（`.t-btn--add`）。

## 结构
- `.t-addr`：最小高 176px，18px 20px 16px，`surface` 底、`line` 边框、`radius-8`。游标所在卡加 `.is-cur`：边框 `acc`、底 `surface-selected`、左上 `▶` 可见。
- 头部：`▶`（`acc`）· 姓名 16px strong · 电话 13px `mute`（中间四位打码 `138 **** 5521`）· 弹性空白 · 状态标签。标签顺序：`本单寄往`（绿描边）、`默认`（`acc` 实底）、地址标签（中性：家 / 公司 / 学校）。
- 正文缩进 24px：地区 13px `mute`，详细地址 15px/1.6 `fg`。
- 底部操作（贴底，32px 小按钮）：`⏎ 用于本单`、`e 编辑`、`space 设为默认`（已是默认时禁用，字色 `disabled`）、`d 删除`（字色 `danger`）。

## 消费方提供
地址数据 `{name, phone, tag, region, line, def}`、是否为本单地址、是否为游标所在、各操作回调。卡片进场与列表行一样逐个淡入。
